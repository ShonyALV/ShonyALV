I'm a Computer Science Engineering student at Yachay Tech (Ecuador).
I work on machine learning for EEG signals, data science projects, and LLM agents.

🔭 Right now I'm working on **EEG digit recognition**: Phase-Frequency Coupling features on 14-channel EEG across 51 subjects, with a first-author paper accepted at ACDSA 2027.
EEG signals are noisy and chaotic, so I spend my days looking for order in something that does not want to be ordered
